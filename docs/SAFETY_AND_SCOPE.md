# Safety and scope

## This Repository handles

- JSONで定義された質問、選択肢、遷移先、結果ID
- 問診フロー全体のグラフ表示
- ブラウザ上で一つの回答経路をたどる操作
- 実装された分岐構造を人間が確認するための表示

## This Repository does not handle

- 医療診断や医学的妥当性の判定
- 患者情報・アカウントの管理
- 医療機関の検索や推薦
- 安心マップ本体のバックエンド処理
- 実運用環境とのデータ連携

## Communication and storage

現在のソースコードには、バックエンドAPIや外部サービスとの通信処理はありません。問診データはRepositoryに含まれる静的JSONから読み込みます。

Traceで選択した回答はReactのメモリ上に一時的に保持します。回答をサーバーへ送信せず、`localStorage`、Cookie、データベース等にも保存しません。ページを再読み込みすると回答履歴は消えます。

## Limitation

このRepositoryは問診フローを可視化するための技術資料であり、医療診断を提供することを目的としたものではありません。

表示されるフローは、安心マップの設計を説明・確認するためのものであり、このRepository単体を医療判断に利用することを想定していません。医学的・運用上の評価は、このviewerの構造検証とは別に行う必要があります。

`triage_level`のない結果に対して、現在のTrace結果画面はGREEN用の表示設定をフォールバックとして使用します。これはJSONにトリアージ値を追加する処理ではありませんが、表示方針は設計・内容面の確認が必要な既知の制約です。
